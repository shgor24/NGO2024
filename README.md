# NGO Administrative System

A Java-based desktop application designed to support the administrative operations of a non-governmental organization (NGO).

The system provides a centralized platform for managing employees, projects, departments and partners, with functionality tailored to different user roles.

## Key Features

- **Role-based access control:** Three user roles (Case Officer, Project Manager and Administrator), each with different permissions and functionality.
- **Project Management:** View, create, update and manage projects, including assigned employees and associated partners.
- **Employee Management:** Manage employee accounts, personal information and departmental assignments.
- **Search & Filtering:** Search for employees and filter projects by status and date range.
- **Statistics:** Generate project cost statistics.
- **Input Validation:** Validate user input using Regular Expressions (RegEx) and a dedicated validation class.

## Getting Started

### Prerequisites

- Java Development Kit (JDK)
- NetBeans IDE
- MySQL
- InfDB class library

### Setup

1. Clone the repository.
2. Open the project in NetBeans.
3. Configure the MySQL database connection.
4. Ensure the InfDB library is correctly included.
5. Build and run the application.
